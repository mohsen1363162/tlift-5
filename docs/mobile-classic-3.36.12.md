# نمای موبایل آشنا — نسخهٔ 3.36.12

> **اصلاح در 3.36.13:** در این نسخه چند امکان قبلی (از جمله کلید سه‌گوش) پشت «نمایش سایر امکانات» پنهان شده بود و جملهٔ «از خانه قابل دسترسی هستند» به‌اندازهٔ کافی دقیق نبود. وضعیت درست و جای هر امکان در [docs/mobile-feature-parity-3.36.13.md](mobile-feature-parity-3.36.13.md) آمده است.

## تغییرات
- صفحهٔ خانه با زمینهٔ خاکستری، سه اقدام «ثبت سرویس»، «ثبت خرابی» و «لیست خرابی»، وضعیت کار فعال، کارهای امروز و کارهای تاریخ گذشته.
- فهرست‌های فشرده با آیکون ساختمان، تاریخ فارسی و امکان مشاهدهٔ همه / کمتر؛ کارهای تاریخ گذشته شامل تمام سرویس‌های تکمیل‌نشده پیش از امروز است.
- نوار پایین چهار گزینهٔ خانه، نقشه، تقویم و سرویس ها؛ کلید سه‌گوش و سایر امکانات قبلی از خانه قابل دسترسی هستند.
- عنوان «اطلاعات سرویس»، کادر آدرس یاسی، جدول جزئیات و بخش «پیوست های این سرویس» با نمایش پیوست‌های واقعی سرویس. عکس‌های پروژه همچنان جداگانه قابل دسترسی هستند.
- تقویم تیره با دکمه‌های قبلی / بعدی و نشانگر روزهای دارای سرویس.
- ابزارهای نصب، به‌روزرسانی و همگام‌سازی در بخش بازشونده نگهداری شده‌اند؛ وضعیت آفلاین از وضعیت واقعی برنامه خوانده می‌شود. هشدار ساعت نمونهٔ عکس جعل نشده است.
- برای ساختمانی که موقعیت ذخیره‌شده ندارد، پیام نبود موقعیت و اقدام ثبت موقعیت نمایش داده می‌شود؛ مختصات پیش‌فرض به‌عنوان موقعیت آن ساختمان نمایش داده نمی‌شود.

## محدوده و حفاظت از اطلاعات
- تغییرات ظاهری به نمای موبایل محدود است؛ ساختار localStorage و IndexedDB تغییر نکرده است.
- هیچ دادهٔ واقعی، گزارش سرویس، صف آفلاین یا بکاپ حذف نشده و اطلاعات نمونهٔ تصاویر وارد برنامه نشده است.
- «ثبت خرابی» مسیر انتخاب ساختمان و شروع سرویس را راهنمایی می‌کند؛ این نسخه گردش‌کار مستقل جدیدی برای خرابی ایجاد نمی‌کند.
- نقشه و سرویس‌های آنلاین موجود همچنان به دسترسی شبکه و سرویس‌های ثالث وابسته‌اند.
- بستهٔ APK عمومی اضافه نشده است.

## بررسی‌ها
- `npm ci` و `npm run build` موفق؛ ساخت شامل TypeScript و بسته‌بندی سی‌پنل است.
- `python3 scripts/check_release.py` موفق: هماهنگی نسخه‌ها، سلامت ZIP و برابری بایت‌به‌بایت با خروجی build؛ بدون آرشیو تو‌در‌تو، APK یا harness آزمایش.
- ۳۳ آزمون مرورگر موفق: ۳ نمای موبایل در عرض‌های ۳۶۰، ۳۹۰ و ۴۸۰؛ ۹ آزمون کاتالوگ؛ ۱۷ بازیابی آفلاین و ۴ smoke.
- ۸ آزمون واحد کاتالوگ موفق.
- تصاویر خانه، سرویس و تقویم حاصل از آزمون بازبینی شدند. آزمون‌های مرورگر از اطلاعات ساختگی و شبکهٔ ایزوله استفاده می‌کنند؛ آزمون نصب واقعی PWA، سرور زنده یا تصاویر آنلاین نقشه محسوب نمی‌شوند.
