# پایدارسازی 3.36.9

## دامنه تغییرات

- رفع ۲۳ خطای TypeScript گزارش‌شده در مرحله بازیابی؛ بدون any یا ts-ignore جدید و بدون تضعیف تنظیمات TypeScript.
- افزودن typecheck به ابتدای npm run build؛ خطای نوع از این پس مانع تولید انتشار می‌شود.
- اصلاح نوع timer مرورگر و شناسه عددی قرارداد انتخاب‌شده در نسخه موبایل.
- استفاده از qty و monthlyServiceFee و devices برای خواندن فیلدهای استاندارد؛ فیلدهای قدیمی همچنان به‌صورت fallback قابل خواندن‌اند. تعریف فیلدهای optional صرفاً تغییر TypeScript است و هیچ مهاجرت یا بازنویسی داده ایجاد نمی‌کند.
- تطبیق شماره قرارداد واگذارشده با no و جلوگیری از تطبیق تصادفی دو مقدار undefined؛ contractNo قدیمی هم قابل خواندن است.
- تکمیل مقدار موقت ماه بدون سرویس با id عددی و paid: false.
- جایگزینی Array.at با دسترسی معادل سازگار با ES2020؛ هدف مرورگر بالاتر برده نشد.
- نسخه package.json، package-lock.json و APP_VERSION برابر 3.36.9.

## آزمون‌ها

چهار تست Playwright روی خروجی production:

1. فرم ورود به‌جای صفحه خالی نمایش داده می‌شود.
2. داشبورد دسکتاپ با نشست مدیر ساختگی نمایش داده می‌شود.
3. فهرست سرویس موبایل باز و ماه‌های قرارداد دارای شناسه عددی باز می‌شوند.
4. رکورد ساختگی صف، سرویس آفلاین و قرارداد پس از reload باقی می‌مانند.

همه تست‌ها context جدید، داده ساختگی و مسدودسازی درخواست‌های خارجی، PHP و WebSocket دارند. bootstrap واقعی با پاسخ خالی جایگزین می‌شود و Service Worker برای ایزوله‌کردن شبکه غیرفعال است. بنابراین این‌ها تست نصب PWA، ورود واقعی، همگام‌سازی واقعی یا بازیابی بک‌آپ نیستند.

## اجرای مجدد

```bash
npm ci
npm run build
python3 scripts/check_release.py
npx playwright install --with-deps chromium
```

در ترمینال جداگانه سرور موقت را اجرا کنید:

```bash
npm run preview -- --host 0.0.0.0 --port 4173
```

سپس:

```bash
npm run test:smoke
```

در صورت وجود Chromium از قبل، مسیر آن را با CHROMIUM_EXECUTABLE_PATH تعیین کنید. SMOKE_BASE_URL پیش‌فرض http://127.0.0.1:4173 است و فقط توسط runner محلی آزمون مصرف می‌شود. این آدرس در برنامه مرورگر کاربران استفاده نمی‌شود.

در محیط این Session دانلود مستقیم مرورگر و بسته‌های سیستم در دسترس نبود؛ Chromium از بسته آزمایشی @sparticuz/chromium خارج از مخزن آماده شد و کتابخانه‌های همراه آن استفاده شدند. اجرای موفق:

```bash
LD_LIBRARY_PATH=/tmp/al2023/lib CHROMIUM_EXECUTABLE_PATH=/tmp/chromium npm run test:smoke
```

باینری مرورگر، گزارش‌ها و فایل‌های موقت به Git اضافه نشده‌اند.

## حفاظت و محدودیت‌ها

هیچ داده واقعی، بک‌آپ، گزارش یا صفی پاک نشده؛ نام کلیدهای localStorage و schema پایگاه IndexedDB تغییر نکرده است. هیچ APK اضافه نشده و استقراری روی هاست انجام نشده است. آرشیو سورس 3.36.7 و bootstrap اصلی حفظ شده‌اند.

۸ آسیب‌پذیری وابستگی‌های قبلی هنوز باقی است (۶ متوسط و ۲ بالا). این مرحله ارتقای اجباری یا عمده وابستگی‌های اجرایی ندارد. آزمون کامل ثبت سرویس، تعارض همگام‌سازی، بازیابی بک‌آپ و کارکرد آفلاین PWA باید در مرحله مستقل با داده آزمایشی اجرا شود.

فایل public/public_html.zip پس از Build تولید می‌شود و scripts/check_release.py تطابق محتوای آن با dist را کنترل می‌کند. پیش از نصب روی cPanel از داده‌های هاست بک‌آپ بگیرید و مسیرهای داده زنده، uploads و بک‌آپ‌ها را حذف یا با داده اولیه جایگزین نکنید.
