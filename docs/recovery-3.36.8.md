## نتیجه کنترل‌ها

- `npm ci`: موفق؛ audit همچنان ۶ آسیب‌پذیری متوسط و ۲ بالا گزارش می‌کند؛ اصلاح اجباری وابستگی‌ها اجرا نشد.
- `npm run build`: موفق؛ PWA و public/public_html.zip تولید شد.
- `python3 scripts/check_release.py`: موفق؛ هماهنگی نسخه‌ها، نبود App خالی، CRC، فایل‌های ضروری، نبود APK/ZIP تودرتو و تطابق بایت‌به‌بایت ZIP با dist کنترل می‌شود. این کنترل جایگزین تست مرورگر نیست.
- `npx tsc -p tsconfig.app.json --noEmit`: ناموفق، ۲۳ diagnostic باقی مانده از سورس بازیابی‌شده؛ شامل ناهماهنگی مدل Contract/MonthService/ServicePartItem، نوع state و تنظیمات NodeJS/Array.at. Vite build این type-check را اجرا نمی‌کند.
- تست مرورگر انجام نشد: دانلود Chromium با ECONNRESET شکست خورد. هیچ ورود یا همگام‌سازی آزمایشی با سرور واقعی انجام نشد.
- کنترل whitespace، فاصله‌های انتهای خطوط CSS بازیابی‌شده را گزارش می‌کند؛ برای حفظ محتوای آرشیو در این مرحله دست‌نخورده مانده‌اند.
